# Osborne Ops — Portfolio Site

**Osborne Ops** is the software engineering and DevOps practice of Steven Osborne.
This site showcases projects, services, and provides a way to get in touch.

Built with **Next.js 16**, **TypeScript**, and **Tailwind CSS v4**. Deployed on **Vercel**.

## Development

```bash
npm run dev     # dev server at localhost:3000
npm run build   # production build
npm run start   # serve production build
npm run lint    # run ESLint
```

## Deploy

Every push to `main` auto-deploys via Vercel's GitHub integration.

## Domain

The site lives at **oaktreeservices.net** (DreamHost DNS → Vercel).

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Vercel (hosting + CI/CD)
- DreamHost DNS
